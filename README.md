# 🚗 VTC Paris — Transfert Chauffeur Privé

Site de réservation de chauffeur privé VTC à Paris et en Île-de-France.

## ✨ Fonctionnalités
- Design moderne et responsive
- Mode sombre / clair
- Formulaire de réservation (Google Apps Script)
- Suivi des courses en temps réel
- Tableau de tarifs
- Section témoignages
- Intégration WhatsApp

## 🚀 Installation
```bash
npm install
npm run dev
```

## 📦 Build
```bash
npm run build
```
